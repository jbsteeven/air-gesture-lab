# Air Gesture Lab

PWA gesture-first sperimentale controllata tramite movimenti della mano rilevati dalla fotocamera frontale, senza visualizzare il flusso video.

## v0.1
- Camera frontale invisibile nell'interfaccia
- Hand tracking MediaPipe
- Cursore virtuale sull'indice
- Pinch per conferma
- Swipe sinistra/destra per navigazione
- Palmo aperto come gesto STOP
- Manifest PWA e service worker

L'accesso alla fotocamera richiede HTTPS (o localhost) e il consenso esplicito dell'utente.
